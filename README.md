# 📊 Amazon Sales Analysis Dashboard

## 📌 Project Overview

The **Amazon Sales Analysis Dashboard** is an interactive Excel-based data analytics project designed to analyze sales performance, identify business trends, and generate meaningful insights from Amazon sales data.

The dashboard uses **Pivot Tables, Pivot Charts, Slicers, KPI Cards, and Timeline filters** to provide an interactive view of sales performance.

---

## 🎯 Objectives

- Analyze overall Amazon sales performance
- Track important sales KPIs
- Identify top-performing products and categories
- Analyze sales trends over time
- Compare sales performance across different segments
- Build an interactive and user-friendly dashboard
- Support data-driven business decision-making

## 📊 Dashboard Features

### 🔹 KPI Analysis

The dashboard provides key performance indicators such as:

- Total Sales
- Total Orders
- Average Sales
- Product Performance
- Category Performance

### 🔹 Sales Analysis

- Sales trends over time
- Category-wise sales performance
- Product-wise performance
- Segment-wise analysis
- Identification of top-performing products

### 🔹 Interactive Filters

Users can dynamically filter the dashboard using:

- Date/Timeline
- Product Category
- Product
- Other available dimensions
